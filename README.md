# إسناد القانونية

موقع مكتب «إسناد القانونية» للمحاماة والاستشارات القانونية (الرياض). موقع **ثابت (Static)** عربي بالكامل من اليمين إلى اليسار، مبني بـHTML وCSS وJavaScript خام **بلا أطر عمل ولا مكتبات خارجية**، ويضم **مساعدًا آليًا للمحادثة** (عربي / English) يعمل بالكود فقط، **بلا مفاتيح API ولا خوادم**.

| | |
|---|---|
| **الصفحات** | 20: الرئيسية، من نحن، فهرس المجالات، 15 صفحة مجال، الأسئلة الشائعة، تواصل معنا |
| **التقنيات** | HTML5 · CSS3 (طبقات + خصائص مخصصة) · JavaScript خام |
| **وقت التشغيل** | لا شيء يُثبَّت: ارفع الملفات على أي استضافة ثابتة |
| **أدوات التطوير** | Python 3.8+ لتوليد الصفحات وبيانات المساعد · Playwright للاختبارات (اختياري) |
| **اللغة والاتجاه** | الموقع `lang="ar" dir="rtl"` · المساعد يدعم English (LTR) |
| **الخطوط** | Amiri (العناوين) · IBM Plex Sans Arabic (النص) عبر Google Fonts |

## المزايا

**الموقع**
- هوية أخضر داكن وذهبي، وصفحة رئيسية كاملة: هيرو بعناوين متناوبة، من نحن، مجالات الممارسة (15) بفلاتر، لماذا إسناد القانونية، دراسات الحالة، آراء العملاء، الاعتمادات المهنية، مركز المعرفة (6 مقالات)، ودعوة للحجز.
- 15 صفحة مجال مستقلة (ما نقدّمه، متى تحتاج الخدمة، المستندات، الأخطاء الشائعة، المحامي المختص، أسئلة المجال، الجهات المختصة).
- نموذج حجز استشارة من 3 خطوات، وأزرار الباقات تعبّئه مسبقًا، ونماذج بوضع تجريبي آمن إلى أن تضبط الوجهة.
- بحث في الموقع (طبقة منبثقة) وبحث في الأسئلة الشائعة.
- «عرض دراسة الحالة» و«اقرأ المقال كاملاً» يفتحان بطاقة `<dialog>` أصلية (Esc وحبس التركيز) ويبقى `<details>` يعمل دون JS.
- خريطة Google لا تلتقط التمرير إلا بعد النقر، وحركة تظهر عند التمرير وتحترم «تقليل الحركة».

**المساعد الآلي**: يجيب من محتوى الموقع نفسه (أكثر من 250 سؤالًا بصيغ ولهجات مختلفة)، ثنائي اللغة، يعرف الصفحة التي أنت فيها وحالة المكتب (مفتوح/مغلق)، ويحوّل المحادثة إلى طلب حجز جاهز. التفاصيل [أدناه](#المساعد-الآلي-الشات).

**الجودة**: صفحات ومعرفة المساعد قابلة لإعادة التوليد بأمر واحد، واختبارات آلية على كل الصفحات، وتباين ألوان مُدقَّق.

## البدء السريع

```bash
# معاينة محلية (من جذر المشروع)
python3 -m http.server 8000        # ثم افتح http://localhost:8000
```

يعمل الموقع أيضًا بفتح `index.html` مباشرة، لكن الخطوط والخريطة والصور تحتاج إنترنت، والمعاينة عبر خادم أقرب للإنتاج.

```bash
# إعادة البناء بعد تعديل المصادر (بهذا الترتيب)
python3 tools/build.py              # الصفحات + js/main.js
python3 tools/build_chat_data.py    # معرفة المساعد (تقرأ الصفحات المبنية)
```

السكربتان لا يحتاجان أي حزم. `build_chat_data.py` يتوقف برسالة واضحة إن تغيّرت بنية صفحة يعتمد عليها (مثل ساعات العمل أو صفحة مجال).

## الإعداد قبل النشر (`CONFIG`)

كل بيانات التواصل في موضع واحد: كائن `CONFIG` في **`tools/main.source.js`** (ثم `python3 tools/build.py`).

```js
var CONFIG = {
  phone: '',          // مثال: '+966 11 000 0000'
  whatsapp: '',       // بالصيغة الدولية، مثال: '966500000000'
  email: '',          // مثال: 'info@yourdomain.sa'
  formEndpoint: '',   // رابط يستقبل POST بصيغة JSON (Formspree وأمثاله أو خادمك)
  social: { li: '', x: '', ig: '', yt: '' }   // روابط الحسابات الكاملة
};
```

| الحقل | يؤثر في | وهو فارغ |
|---|---|---|
| `phone` / `whatsapp` / `email` | أزرار الاتصال وواتساب والنصوص في الموقع وصفحة «تواصل معنا»، **وأزرار الشات** | تبقى النصوص الافتراضية («[أضف رقم الهاتف]»)، ولا تظهر أزرار واتساب/اتصال/بريد في الشات |
| `formEndpoint` | كل النماذج: يُرسَل `POST` بـ`Content-Type: application/json`، ومفاتيحه نص تسميات الحقول | **وضع تجريبي**: يظهر نجاح كاذب ولا يُرسَل شيء (تحذير في الكونسول) |
| `social` | أيقونات التواصل الاجتماعي وردّ المساعد عنها | الأيقونات بلا روابط، ويقول المساعد إن الحسابات غير معروضة |

خيارات اختيارية للمساعد في الكائن نفسه (بعد `window.SITE_CONFIG = CONFIG`): `SITE_CONFIG.chat = { teaser: false }` يعطّل التنبيه اللطيف فوق الزر، و`{ teaserDelay: 40000 }` يغيّر مدته (ملّي ثانية).

## تحرير المحتوى: أين أعدّل ماذا؟

| أريد تعديل… | أعدّل | ثم أشغّل |
|---|---|---|
| نص أي صفحة (الرئيسية، من نحن، الأسئلة الشائعة، تواصل، بطاقات المجالات، المقالات…) | `tools/source.html` | `build.py` ثم `build_chat_data.py` |
| الحالات والجهات المختصة والأخطاء الشائعة وسؤال كل مجال | `tools/content.py` | `build.py` ثم `build_chat_data.py` |
| الخدمات ومتى تحتاج والمستندات والمحامي المختص لكل مجال | بطاقة المجال `.pc` في `tools/source.html` | `build.py` ثم `build_chat_data.py` |
| `CONFIG` وفهرس البحث (`DATA`) | `tools/main.source.js` | `build.py` |
| الألوان والخطوط والمسافات | ملفات `css/` (انظر [نظام التصميم](#نظام-التصميم)) | — |
| ردود المساعد وكلماته المفتاحية | `js/chat.js` (والإنجليزية `js/chat-en.js`) | `tests/run_all.py` |

> فهرس البحث `DATA` في `main.source.js` يدوي: إن أضفت صفحة أو مقالًا أضفه هناك ليظهر في نتائج البحث.

## نظام التصميم

**الألوان والمتغيّرات** (مُعرَّفة في `:root`):

| المتغيّر | القيمة | الاستخدام |
|---|---|---|
| `--g` | `#0a2c2d` | الأخضر الداكن (الهوية) |
| `--g2` | `#1b4a47` | أخضر داكن ثانٍ |
| `--au` | `#b8aa66` | الذهبي |
| `--au-d` | `#8a6d1f` | ذهبي غامق للنصوص فوق الأبيض |
| `--au-l` | `#e4d39a` | ذهبي فاتح للنصوص فوق الداكن |
| `--c` | `#fff8ed` | كريمي |
| `--ink` | `#151515` | لون النص |
| `--mu` | `#555` | نص ثانوي |
| `--rad` | `12px` | نصف قطر الزوايا |
| `--rad-s` | `8px` | زوايا صغيرة (الأزرار) |

- **الخطوط**: `Amiri` للعناوين (`--serif`) و`IBM Plex Sans Arabic` للنص. تُحمَّل من Google Fonts مع بدائل نظامية.
- **الاتجاه**: خصائص CSS المنطقية (`inline-start/end`) حتى ينقلب التخطيط بين RTL وLTR دون تكرار.
- **الأزرار**: الأساسي ذهبي `.bt.f`، والثانوي بحدّ، ومدخل الشات حبّة عاجية بحدّ ذهبي وأيقونة خضراء دائرية.
- **الأقسام**: كل قسم بخلفية بيضاء أو كريمية أو خضراء داكنة؛ ملاحظات `.ix` بلوحة خضراء داكنة أو بتدرّج `#f5f9f7→#e8f1ed`.
- **الحركة**: ظهور عند التمرير وأزرار مغناطيسية (ماوس فقط)، وكلها تتوقف مع `prefers-reduced-motion`.

## المساعد الآلي (الشات)

زر عائم أسفل يسار الشاشة يفتح نافذة محادثة. **لا يتصل بأي خادم**: كل شيء في المتصفح.

**ما يجيب عنه** (كله من محتوى الموقع، ولا يخترع معلومة):
- مجالات الممارسة الخمسة عشر: ما نتولاه، الخدمات، متى تحتاج محاميًا، المستندات، الأخطاء الشائعة، المحامي المختص، و75 حالة بعينها.
- الأتعاب والاستشارة الأولى والسرية والوكالة، ومراحل العمل ومدة القضية، والمواعيد والعنوان وقنوات التواصل، والحالات العاجلة والاستدعاء، والاستشارة عن بُعد، والأسئلة الشائعة الـ33، ومقالات مركز المعرفة الستة، والفريق والرؤية والمحطات.
- ما لا يذكره الموقع (وظائف، طرق دفع…) يقول إنه غير مذكور ويحوّل لقنوات التواصل؛ والخارج عن النطاق (ذهب، طقس…) يعتذر عنه.

**الفهم**: توحيد الهمزات والتاء المربوطة والبادئات، تسامح مع الأخطاء الإملائية والحروف المكررة (مقيّد بمفردات الموقع)، لهجات شائعة، أسئلة مركّبة («كم الأتعاب وأين المكتب؟»)، «هل تقصد؟» عند اللبس بين مجالين، فهم «نعم/لا»، تذكّر المجال المتحدَّث عنه، واقتراح أقرب الأسئلة بدل الرد الفارغ.

**الواجهة**: حالة المكتب (مفتوح/مغلق) بتوقيت الرياض، اقتراحات أثناء الكتابة بالأسهم وEnter، قائمة ⋯ (نسخ المحادثة، محادثة جديدة)، زر EN/عربي (ويتبدّل تلقائيًا إن كتبت بالإنجليزية)، تنبيه لطيف مرة في الجلسة، وبملء الشاشة مع حبس تركيز على الجوال.

**من المحادثة إلى الحجز**: تدفّق «ابدأ الطلب هنا» (الاسم، نوع المسألة، الأولوية) ينتهي بملخص وأزرار: واتساب برسالة جاهزة، هاتف، بريد، «نسخ الملخص»، و«نموذج حجز الاستشارة» الذي يفتح `contact.html` **وقد عُبّئت** حقول نوع القضية والأولوية والاسم (مع ملاحظة «راجعها قبل الإرسال»). لا يُرسَل شيء تلقائيًا.

**الملفات والمعرفة**

```
js/chat.js        المحرّك: النوايا، المطابقة، الواجهة، التدفّقات
```

- بعد تعديل الأسئلة الشائعة أو المجالات أو ساعات العمل أو المقالات أو من نحن: `python3 tools/build_chat_data.py`.
- إضافة موضوع جديد: أضف نيّة إلى المصفوفة `I` (معرّف وكلمات مفتاحية؛ `$` في آخر الكلمة تعني مطابقة النهاية تمامًا) ثم ردًّا في `arAnswer`، وأضف مقابلها الإنجليزي في `chat-en.js` إن لزم. شغّل الاختبارات بعدها.

**الخصوصية**: لا طلبات شبكة سوى تحميل ملفات المساعد نفسها. تُحفظ المحادثة في `sessionStorage` (تزول بإغلاق التبويب)، وتُعرض النصوص بـ`textContent` فلا تُنفَّذ أكواد، ولا يُرسَل شيء إلا إذا نقر الزائر بنفسه على واتساب أو البريد أو الاتصال.

**حدود معروفة**: مطابقة كلمات عربية وليست ذكاءً اصطناعيًا؛ تفاصيل المجالات والمقالات بالعربية فقط (الإنجليزية تغطي المواضيع الرئيسية)؛ والردود تنقل ما في الموقع، فمراجعة نصوصه قانونيًا تنطبق عليها.

## الاختبارات

اختبارات Playwright (Chromium) على المساعد وعلى الصفحات الـ20، تفتح الملفات من القرص ولا تحتاج خادمًا.

```bash
pip install -r tests/requirements.txt && playwright install chromium
python3 tests/run_all.py              # كل الاختبارات
python3 tests/run_all.py features     # ما يطابق الكلمة في اسم الملف
```

## إمكانية الوصول

- رابط «تخطّي إلى المحتوى»، وإطار تركيز واضح `:focus-visible`، وتنقّل كامل بلوحة المفاتيح.
- بطاقات `<dialog>` أصلية (Esc، حبس التركيز)، وللمساعد `role="dialog"` وسجل `role="log"` و`aria-live` و`aria-modal` على الجوال مع حبس Tab.
- احترام `prefers-reduced-motion` في كل الحركات.
- تباين الألوان مُدقَّق آليًا في الأقسام المُعاد تلوينها (≥ 4.5:1 للنصوص العادية).
- RTL حقيقي بخصائص منطقية، وسمات `lang` للنصوص الإنجليزية داخل الصفحة.

## الأداء

- بلا إطار عمل ولا مكتبات: مجموع الـCSS نحو 165 KB، وكل سكربت صغير ومؤجَّل (`defer`).
- المعرفة الموسّعة (`chat-kb.js`) والحزمة الإنجليزية تُحمَّلان عند الحاجة فقط.
- الخريطة `loading="lazy"`.
- **تحسينات موصى بها قبل الإطلاق**: استضافة الخطوط محليًا (وحذف العائلتين غير المستخدمة تقريبًا: Aref Ruqaa وEl Messiri)، واستضافة الصور محليًا بدل Unsplash، وتفعيل ضغط gzip/brotli وترويسات التخزين المؤقت للأصول.

## SEO والبيانات المنظمة

- كل صفحة بعنوان ووصف وسمات Open Graph/Twitter، والرئيسية بـJSON-LD من النوع `LegalService` (العنوان، الهاتف، الساعات، الإحداثيات، الشريك المدير).
- **غير موجود بعد** (أضفه قبل الإطلاق): `canonical`، وصورة `og:image`، وأيقونة المتصفح (favicon)، و`robots.txt`، و`sitemap.xml`. وراجع بيانات JSON-LD وطابقها مع الواقع.

## الخصوصية والأمان

- لا كوكيز ولا تتبّع ولا تحليلات مضمّنة. النماذج في الوضع التجريبي لا ترسل شيئًا حتى تضبط `formEndpoint`.
- الطلبات الخارجية الوحيدة: Google Fonts (`fonts.googleapis.com`, `fonts.gstatic.com`)، وإطار الخريطة (`www.google.com`)، وصور `images.unsplash.com` عبر CSS.
- لا `eval` ولا مكتبات طرف ثالث. مثال أوّلي لـCSP (اختبره قبل الاعتماد):
  `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src https://fonts.gstatic.com; img-src 'self' data: https://images.unsplash.com; frame-src https://www.google.com; connect-src 'self' <formEndpoint>`
- فعّل HTTPS، وأضف `X-Content-Type-Options` و`Referrer-Policy` و`Permissions-Policy` من الاستضافة.

## التوافق مع المتصفحات

المتصفحات الحديثة (تقريبًا: Chrome/Edge 108+، Firefox 104+، Safari 16+). يعتمد على خصائص CSS المنطقية و`:where()` و`dvh` وخصائص `translate/rotate` المنفصلة و`<dialog>` و`IntersectionObserver` و`Intl.DateTimeFormat` بالمنطقة الزمنية. في غير ذلك يبقى المحتوى مقروءًا والروابط تعمل (تحسين تدريجي).

## النشر
